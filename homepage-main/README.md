# Gedu Homepage

Trang giới thiệu chính thức cho Gedu - Giải pháp quản lý trường học toàn diện.

## Tổng quan

Gedu là nền tảng mạnh mẽ giúp các trường học quản lý:
- Thông tin và tiến độ học tập của học sinh
- Công tác giáo viên và hành chính
- Giao tiếp giữa các bên liên quan
- Phân bổ tài nguyên và lập lịch
- Ra quyết định dựa trên dữ liệu

## Cấu trúc dự án

```
homepage/
├── index.html      # Trang chủ
├── styles.css      # File CSS
├── images/         # Thư mục chứa hình ảnh
└── README.md       # Tài liệu dự án
```

## Tính năng

Trang web giới thiệu các tính năng và lợi ích chính của Gedu:
- Thiết kế hiện đại, tương thích với mọi thiết bị
- Hiệu ứng và hoạt ảnh đẹp mắt
- Giao diện người dùng thân thiện
- Tích hợp biểu mẫu liên hệ
- Tối ưu hóa SEO
- Hiệu ứng particles.js ấn tượng
- Thiết kế theo phong cách Material Design

## Tuân thủ pháp lý

Trang web được thiết kế để đáp ứng yêu cầu của MailerSend:
- Thông tin công ty rõ ràng
- Giao diện chuyên nghiệp
- Thông tin liên hệ đầy đủ
- Thông báo bản quyền

## Phát triển

Để xem trang web trên máy tính cá nhân:
1. Clone repository này
2. Mở file `index.html` trong trình duyệt web
3. Không cần cài đặt thêm dependencies
